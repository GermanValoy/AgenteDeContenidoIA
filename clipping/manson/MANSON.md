## Regenerar

```
cd clipping/manson
python -I build.py              # los 3 clips
python -I build.py 03-wife      # uno solo
```
- **Transcripción:** `python ../transcribir.py audio.m4a ../fuentes/manson/nombre`, con Whisper local. Se usa porque YouTube bloquea los subtítulos con error 429. No usar `-I`, porque faster-whisper está en el site-packages del usuario.
- **Audio:** al descargar, elegir el **audio original en inglés** (`ba[language^=en]`). YouTube muestra este canal doblado al español.
